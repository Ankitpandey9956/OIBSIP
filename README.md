# 1. 📈 Retail Sales — Exploratory Data Analysis

### File

`DataAnalytics-L1-EDARetailSales.ipynb`

### Objective

The objective of this project is to perform **Exploratory Data Analysis (EDA)** on retail sales data and identify useful patterns, trends, relationships, and business insights.

* Loaded and inspected the dataset
* Checked dataset structure and data types
* Calculated descriptive statistics
* Checked for missing values
* Analyzed sales trends
* Grouped data by relevant categories and time periods
* Identified top-performing products/categories
* Created visualizations to understand sales patterns
* Generated business insights and recommendations
* Analyzed correlations between numerical variables

### Visualizations

The project includes visualizations such as:

* 📊 Bar charts
* 📈 Line charts
* 🔥 Correlation heatmaps
* 📉 Distribution plots
* 📦 Other exploratory visualizations

### Key Learning

This project helped develop practical skills in **exploratory data analysis, data visualization, statistical interpretation, and extracting business insights from datasets**.

# 3. 🏠 House Price Prediction with Linear Regression

### File

`DataAnalytics-L2-PredHousePricesWithLinearRegression.ipynb`

### Objective

The objective of this project is to build a **Linear Regression machine learning model** to predict house prices based on available features.

### Machine Learning Workflow

The project follows the typical machine learning workflow:

```text
Dataset
   ↓
Data Understanding
   ↓
Data Preprocessing
   ↓
Feature Selection
   ↓
Encoding Categorical Variables
   ↓
Train-Test Split
   ↓
Linear Regression
   ↓
Model Prediction
   ↓
Model Evaluation
   ↓
Visualization & Analysis
```

### Key Activities

* Loaded and explored the housing dataset
* Examined numerical and categorical features
* Checked the target variable
* Analyzed the distribution of house prices
* Selected relevant predictors
* Applied categorical encoding where required
* Split the dataset into training and testing sets
* Trained a Linear Regression model
* Generated predictions
* Evaluated model performance

### Evaluation Metrics

The model was evaluated using commonly used regression metrics:

* **Mean Squared Error (MSE)**
* **Root Mean Squared Error (RMSE)**
* **R² Score**

### Visualizations

The project includes visual analysis such as:

* Actual vs Predicted Prices
* Residual Analysis
* Target Variable Distribution
* Feature/Correlation Analysis

### Key Learning

This project provided practical experience with **supervised machine learning, regression, feature preprocessing, model evaluation, and interpreting model predictions**.
